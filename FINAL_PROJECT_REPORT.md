**Project Title:** Urban Houseplant Care & Watering Schedule App

**Project Features:**
By the end of this course, implemented features:
a) **Zero-Login Dashboard:** Instant access to the app's main interface without internet dependency or cloud authentication.
b) **Local Plant Inventory (CRUD):** Users can add, edit, and delete plants with photos saved locally using Hive.
c) **Offline Exact Alarm Notifications:** Proper implementation of "buzz" alerts for watering and care tasks that work without internet.
d) **Care History Timeline:** A detailed log of all completed care tasks stored securely on the device.
e) **Embedded Offline Care Guide:** A bundled static database with care instructions for popular houseplants.
f) **Online Wikipedia Integration:** Hybrid search feature to fetch live summaries and images when connected to the internet.

**Future Enhancements:**
Following enhancement can be added to the current system which will improve the system.
a) **Light/Dark Sensor Integration:** Using ambient light sensors to detect if a plant spot is optimal.
b) **Data Backup & Restore:** Allowing users to export/import their local database to Google Drive.
c) **Advanced Plant Recognition:** Using local machine learning (TFLite) to identify species automatically via camera.
d) **Weather API Integration:** Smart-skipping notifications based on local humidity or rain forecasts.
